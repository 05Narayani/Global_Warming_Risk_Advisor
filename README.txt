GLOBAL WARMING RISK ADVISOR
===========================

Files:
- index.html: Complete interactive website (HTML, CSS, JavaScript in one file).

How to run:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No installation or internet connection is needed for the interactive features.
   The external climate-data links require an internet connection.

Features:
- Interactive climate-risk screening calculator
- Hazard explorer for heat, flooding, drought, and sea-level rise
- Action checklist with progress tracking
- Links to trusted climate data resources

Note:
The screening score is educational and illustrative, not an official or scientifically validated local risk prediction.
